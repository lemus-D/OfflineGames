# Yes-General

> I want to make a strategy game somewhere between catan and pre civilization
> bronze age which is a little flash game people used to play.

That is the original pitch. Design conversation turned it into the loop below.
**Catan influence is the hex map only** — no trading, no dice yields, no Catan
placement rules.

**A basic structure is in this folder and playable.** Logistics (road raids by
players, action economy polish, AI search) still iterate in play.

Read [../docs/TECHNICAL-DECISIONS.md](../docs/TECHNICAL-DECISIONS.md) first.

Headings marked **[decided]** should not change without asking. Headings marked
**[proposal]** are opening bids — implement, then tune by playing.

---

## What kind of game this is **[decided]**

A bronze-age hex conquest game. You claim hexes, build gather structures, connect
yields to your capital with roads, raise troops, and auto-resolve fights against
AI rivals. Random events (famine, raids, storms) and stronger AI define
difficulty. A match lasts about 15–40 minutes.

Win by owning the whole map, by best land+resource score when turns end, or by
completing an Ancient Wonder.

---

## Inherited technical rules

- Ships as an installable PWA, playable offline (D1).
- No build step, plain ES modules, no runtime dependencies (D2).
- All art generated by code, zero asset files (D3).
- Saves namespaced `yes-general.v1.*`, versioned, keyed by name (D8).
- Deterministic simulation, no `Math.random()` (D9). Maps and combat rolls use
  a seeded RNG.
- Shared code copied from other games rather than imported (D7).
- **Content is data-driven from the first commit** — resources, buildings,
  events, modes, difficulty, combat constants live in `src/data/content.js`.

---

## Session and modes **[decided]**

- Full game ~15–40 minutes.
- Modes change **turn budget** and map radius (short / standard / long).
- Clock is discrete **turns until end**; timed victory evaluates if nobody won
  earlier.

## Difficulty **[decided]**

Higher difficulty means all of:

- more frequent negative events,
- more AI opponents,
- stronger AI play (skill bias in the stub AI; search eval later).

## Map and economy **[decided]**

- Hex map of hex tiles; each hex has resource properties.
- Some resources need a **gather structure** before they produce.
- Yields must travel to the **capital** along **roads**. No path → no stockpile.
- Roads can be destroyed (events for now; player/AI road raids still open).

## Combat **[decided]**

- Auto-resolve on the contested hex.
- Troop counts → win probability + seeded roll.
- No tactical mini-game.

## Victory **[decided]** — any of:

1. **Conquest** — sole survivor / own the whole map.
2. **Timed score** — when turns end, highest resources + land value.
3. **Wonder** — pay the wonder cost at your capital.

## Opponents **[decided]**

- AI civs on the same map.
- v1 AI is a skill-biased heuristic stub.
- Later: search over next states + weighted board evaluation. TBD.

## Module map **[proposal]**

| path | role |
|---|---|
| `server.js` | zero-dependency static server (default port 5181) |
| `src/data/content.js` | modes, difficulty, resources, buildings, events, combat |
| `src/game/hex.js` | axial hex math + seeded map |
| `src/game/roads.js` | capital connectivity |
| `src/game/combat.js` | troop-odds resolve |
| `src/game/match.js` | turn loop, build/recruit/attack, victory |
| `src/game/ai.js` | AI stub |
| `src/game/render.js` | Canvas 2D hex draw |
| `src/main.js` | menu / HUD / input |
